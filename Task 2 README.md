# Task 2: Stock Portfolio Tracker

## Project Overview
The Stock Portfolio Tracker is a Python application that calculates the total investment value of a stock portfolio using predefined stock prices. It accepts stock names and quantities from the user and calculates individual and overall investment values.

## Objectives
- Store stock prices using dictionaries.
- Accept stock names and quantities.
- Calculate individual stock values.
- Calculate total portfolio investment.

## Features
- Hardcoded stock price dictionary.
- User input for stock symbols and quantities.
- Automatic investment calculations.
- Total portfolio value display.
- Optional saving of results to a file.

## Technologies Used
Python, Dictionaries, User Input, Loops, Arithmetic Operations, File Handling.

## How to Run
```bash
python stock_tracker.py
```
