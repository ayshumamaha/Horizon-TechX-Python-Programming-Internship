# Task 3: Task Automation with Python Scripts

## Project Overview
Task Automation with Python Scripts demonstrates how Python can automate repetitive activities. The project implements one selected automation task, such as moving JPG files between folders, extracting email addresses from a text file, or retrieving and storing a webpage title.

## Objectives
- Understand task automation using Python.
- Automate a repetitive activity.
- Work with files and directories.
- Apply Python modules for data processing.

## Features
- Automates a selected task.
- Reduces manual effort.
- Uses file handling and Python modules.
- Displays the result of the automation process.

## Technologies Used
Python, OS, Shutil, Regular Expressions, Requests, File Handling.

## How to Run
```bash
python task_automation.py
```
