# Task 1: Hangman Game

## Project Overview
The Hangman Game is a simple text-based Python application in which the player attempts to guess a hidden word by entering one letter at a time. The program randomly selects a word from a predefined list and allows a maximum of six incorrect guesses.

## Objectives
- Develop a word-guessing game using Python.
- Apply loops and conditional statements.
- Use random word selection.
- Handle user input and track guesses.

## Features
- Five predefined words.
- Random word selection.
- Letter-by-letter guessing.
- Maximum of six incorrect attempts.
- Win and lose messages.

## Technologies Used
Python, Random Module, Lists, Strings, While Loop, Conditional Statements.

## How to Run
```bash
python hangman.py
```
