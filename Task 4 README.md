# Task 4: Basic Chatbot

## Project Overview
The Basic Chatbot is a simple rule-based conversational application developed using Python. It accepts messages from users and responds with predefined replies to common inputs such as greetings, questions, and farewell messages.

## Objectives
- Develop a basic chatbot using Python.
- Understand rule-based conversation logic.
- Apply conditional statements and functions.
- Handle repeated user interactions.

## Features
- Accepts user messages.
- Responds to greetings.
- Provides predefined replies.
- Handles unknown messages.
- Ends the conversation when the user says goodbye.

## Technologies Used
Python, Functions, If-Elif Statements, While Loop, Strings, Input/Output.

## How to Run
```bash
python chatbot.py
```
